# external_odb_conversion

external_odb_conversion converts an Abaqus ODB that was not generated by the dataset-generation pipeline into the CSV format required by the MeshGraphNet. It extracts the peak nodal temperature from the selected analysis step and calculates the same geometric features and graph edges used for generated samples.

Because the ODB was produced externally, no Abaqus solve time is available. The original ODB is not deleted after conversion.

# How to use

First create a sample folder with the following structure:

```text
datasets\dataset_name\split\sample_name
```

Place the ODB in this folder and give it the same name as the sample. For example:

```text
datasets\test\test\HT_overheating_tensilebar\HT_overheating_tensilebar.odb
```

Update `conversion_config.json` so that it describes the ODB, instance and analysis step to process.

Open Command Prompt in the repository root, for example:

```bat
cd /d C:\PBF-MeshGraphNet
```

Run the conversion using Abaqus Python:

```bat
abq2021 python external_odb_conversion\abaqus_external_odb_to_csv.py
```

Replace `abq2021` with the appropriate Abaqus command if a different version is installed. The project virtual environment is not used for this script because access to the ODB requires the Python interpreter supplied by Abaqus.

The conversion creates the following files in the sample folder:

```text
sample_name.csv
sample_name_edges.csv
sample_name_global.json
sample_name_extraction_metadata.json
```

The global-feature JSON is generated automatically if it does not already exist. If the main CSV already exists, its generation is skipped. Delete the existing CSV before running the script if the sample needs to be regenerated.

The configured analysis step must contain nodal `NT11` temperature output for the selected part instance.

# conversion_config

Here is an overview of the parameters in `conversion_config.json`:

* `dataset_name`: name of the dataset folder under `datasets`.
* `split`: dataset subdivision in which the sample is stored, such as `train`, `val`, `test` or a dedicated external-sample split.
* `sample_name`: name of the sample folder and ODB file. The folder and ODB must both use this name.
* `target_instance_name`: exact name of the part instance to extract from the ODB. Valid instance names are reported if the configured name cannot be found.
* `step_name`: exact name of the Abaqus analysis step containing the temperature results. Valid step names are reported if the configured name cannot be found.
