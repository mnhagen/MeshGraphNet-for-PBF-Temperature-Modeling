# Title

This folder is a cleaned-up version of the code I wrote for NLR as part of my three month internship. The goal of this project was to produce a proof of concept showing how machine learning might be used for the engineers in the AVMC group. The project then became using graph neural networks, specifically meshgraphnets, to predict the peak temperature reached across a part printed using Laser Powder Bed Fusion (LPBF).

To be able to use this code, copy it to your local machine. I placed the folder directly in C:, so placing it here would make for the most "plug and play" experience. To start, install a virtual environment. The requirements.txt folder contains all the packages needed to run the code. To set up the virtual environment, navigate to the root folder in cmd and run the following commands to create and activate a virtual environment:

```text
python -m venv .venv 
.venv\Scripts\activate
```

Then install the required packages:

```text
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

This python installation will be used for most of the code.

Running the dataset generation requires Abaqus, a numerical solver software. Install Abaqus 2021 as the plugin used at NLR for PBF simulation is designed for this version. To get familiar with Abaqus, I recommend following the PBF tutorial created by Tim. While interacting with the Abaqus interface is not necessary if you follow my implementation, it is useful to understand the basics of Abaqus. If interested, you can talk to Tim about getting access to it. 

The main functionality of this project has been divided into four folders:

- dataset_generation
- external_odb_conversion
- model_training
- model_testing

A short description of all the folders in this project can be found below. Further details for the four main folders listed above can be found in README.md files in each folder.

## dataset_generation

- This folder contains the code to generate datasets for model training, validation and testing.

## datasets

- This folder contains the datasets generated by dataset_generation. The dataset used for the model the internship report is present in this folder under example_dataset. Two external samples, meaning not generated by the pipeline in dataset_generation, are also present in this folder.

## external_odb_conversion

- When abaqus has solved a geometry, the output is an .odb file. To be usable as input to the model, this file must be converted to a .csv file and many new features must be calculated. This is done in dataset_generation for samples generated by the script, but you might want to test .odb files not generated by this pipeline. This folder contains the code to generate .csv files suitable for use in the model from .odb files.

## model_testing

- This folder contains the code to evaluate and visualize the model and its predictions.

## models

-This folder contains trained models. The model used in my report is present in this folder under example_model.

## shared

-Contains scripts that are required by scripts in multiple folders.
